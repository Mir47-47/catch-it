# 캠퍼스 픽 (가칭) — 맞춤형 교내 정보 큐레이션 도구

학교 곳곳에 흩어진 공지·장학·행사·채용 정보를 자동으로 모아, 학생 각자의 관심사(학과·학년·관심 카테고리·키워드)에 맞는 것만 골라 보여주는 싱크인사이트 플랫폼 위젯 도구. 실무 프로젝트 랩 10조.

## 구성 (계획)
| 축 | 기술 | 역할 |
|---|---|---|
| Frontend | React · TypeScript · Vite | 관심사 설정, 맞춤 정보 피드(정렬·검색·필터·D-day) |
| Backend | Spring Boot (Java 17) | `/api/tools/campus-pick/...` API, 관심사·게시글 저장, 정기 수집 배치 |
| Core | Python · FastAPI | 교내 게시판 크롤링, 키워드 규칙 분류, 마감일 추출, 추천 점수 |

흐름: 크롤링 → 분류·대상·마감일 추출 → 관심사 일치도 점수 → 피드

## 브랜치
- `main`: 기본 브랜치. 검증된 작업만 병합한다.
- `crawlar`: Core 교내 게시판 수집기와 웹 목록 데모(충남대 본부·컴퓨터인공지능학부·경영학부). 실행 방법은 해당 브랜치 README를 본다.

## 저장소 규칙
- 수행계획서 등 문서 원본(docx·pdf)은 저장소에 올리지 않고 팀 공유 경로로 관리한다.
- 비밀값(API 키 등)은 환경변수로만 넣고 커밋하지 않는다.
